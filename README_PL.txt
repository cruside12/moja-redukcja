MOJA REDUKCJA v2
Wgraj wszystkie pliki bezpośrednio do repozytorium GitHub (nie ZIP).
index.html musi być w głównym katalogu.
GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.

Nowe funkcje:
- podgląd kolejnych dni
- wybór dnia i edycja planu dnia
- edycja/dodawanie/usuwanie posiłków
- edycja kalorii i białka
- edycja treningów
- przypomnienia: posiłki, trening, ważenie
- cel kroków
- historia wagi
- ustawienia celu kalorii, białka i masy
- eksport/import danych
- reset danych
- działanie offline po pierwszym załadowaniu

Po zmianie plików na GitHubie odczekaj chwilę na publikację Pages. Na iPhonie Safari -> Udostępnij -> Dodaj do ekranu początkowego.
